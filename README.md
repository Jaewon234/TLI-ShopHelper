# 신들의 강복 도우미 (TLI-ShopHelper)

토치라이트: 인피니트의 **신들의 강복** 상점을 열면 자동으로 켜져서, 사면 이득인 칸을 게임 화면 위에 바로 표시해 주는 도우미입니다.
트레이 메뉴에서 **제작비 계산**과 **부귀·숭고 스킬 레벨업** 계산기도 쓸 수 있습니다.

- 설치 필요 없음: 압축을 풀고 `ShopHelper.exe` 실행
- 자동 업데이트: 새 버전이 나오면 알림 → 누르면 받아서 바꾸고 다시 시작 (시세·설정은 그대로)
- 게임을 건드리지 않음: 게임 로그 파일(`UE_game.log`)과 화면만 읽습니다. 게임 메모리·네트워크·키 입력은 건드리지 않습니다.

## 다운로드

[Releases](../../releases/latest) 에서 `ShopHelper.zip` 을 받아 원하는 폴더에 압축을 풀고 `ShopHelper.exe` 를 실행하세요.

- Windows 10 / 11 (64비트)
- 게임은 **창 모드** 또는 **테두리 없는 창 모드** (전체 화면 모드에서는 화면을 읽지 못할 수 있습니다)
- zip 안에서 바로 실행하지 말고 꼭 압축을 푼 뒤 실행하세요. (시세·설정이 그 폴더에 저장됩니다)

자세한 사용법은 zip 안의 `사용법.txt` 에 있습니다.

## 기능

### 1. 신들의 강복 오버레이
상점을 열면 칸마다 판정을 표시하고, 상점을 닫으면 사라집니다. 기본은 **결정화 기준**(팔아서 결정으로 받을 때, 수수료 12.5% 떼고 올림)입니다.

| 표시 | 뜻 |
|---|---|
| 초록 빛 테두리 + `구매 +N결` | 사면 N 결정 이득 (추천 기준 이상) |
| 어둡게 + 초록 글씨 | 이득이지만 추천 기준 미달 |
| 어둡게 + 빨간 `-N결` | 손해 |
| 회색 | 시세를 모르는 항목 |
| 표시 없음 | 매진, 신비의 휘석(도박) |

- **시세 입력**: 상점 안 왼쪽 아래 [시세 입력] 버튼, 또는 트레이 메뉴 / `Ctrl+Shift+P`. 단위는 1개당 결정입니다.
- **순이익**: 산 칸들의 이득 − 새로고침 횟수 × 휘석 50개 (켠 뒤부터, 트레이 메뉴에서 초기화)
- **자동 읽기**: 처음에 숫자를 잘못 읽어도 0.1~1초마다 다시 읽어 바로잡습니다.

### 2. 제작비 계산 (트레이 메뉴)
장비 옵션을 직접 붙일 때 드는 평균 비용을 계산합니다.

- 레벨 100 / 86 / 82, 한손 / 양손(재료 2배), 보정 %(운이 나쁠 때 대비, 120 = 1.2배)
- 재료 시세와 등급(초급·진급·절대자)별 옵션 개수를 넣으면 제작비가 나오고, 베이스 비용(보정 없음)을 더해 총 비용을 보여 줍니다.
- 0T = 1T 붙이기 + 승급 (승급에 실패해도 1T 는 남음). 86레벨은 1T, 82레벨은 2T 까지이고 초급·진급만 됩니다.
- 옵션 개수와 베이스 비용은 레벨마다 따로 저장됩니다.

### 3. 스킬 레벨업 — 부귀·숭고 (트레이 메뉴)
재료 스킬(같은 종류, 0티어 +10 / 1티어 +5 / 2티어 +2)로 상승치 50 을 가장 싸게 채우는 조합을 찾습니다.

1. 게임에서 올릴 스킬로 같은 스킬 필터 검색을 한 번 합니다.
2. 계산기의 0티어 **[기록]** 을 누르고, 게임에서 0티어 범위로 가격 검색 → 매물 목록이 자동으로 들어옵니다.
3. 1티어, 2티어도 같은 방식으로 기록합니다.

- 실제 매물 가격 목록으로 계산하고, 50 을 넘겨도 더 싸면 그 조합을 고릅니다 (넘친 만큼은 무효로 표시).
- 총 비용 = 스킬 재료비 + 영감 재료 시세 × 500 + 베이스 비용
- 부귀·숭고 스킬 이름 312개가 들어 있습니다 (출처: [tlidb](https://tlidb.com/ko/Noble_Support_Skill)).

두 계산기 모두 닫을 때까지 게임 위에 떠 있고, 입력칸을 누를 때만 키보드를 가져갑니다 (그 밖에는 게임 포커스를 뺏지 않음).

## 파일 위치

```
ShopHelper\
├─ ShopHelper.exe
├─ 사용법.txt, THIRD_PARTY.txt
├─ helper.log          동작 기록 (문제가 있을 때 보내 주세요)
├─ 설정\               prices.json(시세), settings.json(설정), calc.json(계산기 입력값)
├─ 캡처\               '지금 화면 그대로 저장' (Ctrl+Shift+S) 한 공유용 스크린샷
└─ 문제확인\           '현재 화면 저장' 한 오류 확인용 캡처
```

- 폴더째 다른 PC 로 복사하면 시세와 계산기 값도 같이 옮겨집니다.
- 자동 업데이트는 `설정`, `캡처`, `문제확인` 폴더와 `helper.log` 를 건드리지 않습니다.
- 오버레이와 계산기 창은 글자 인식에 섞이지 않도록 일반 캡처 도구에는 찍히지 않습니다. 보이는 그대로 찍으려면 `Ctrl+Shift+S` 를 쓰세요.

## 문제가 있을 때

| 증상 | 확인할 것 |
|---|---|
| 상점을 열어도 아무것도 안 뜸 | `helper.log` 에 `로그:` 줄(게임 로그 경로)과 `상점 열림` 이 찍히는지 |
| 칸을 잘못 읽음 / 테두리가 어긋남 | 상점을 연 채 트레이 메뉴 > **현재 화면 저장** → `문제확인` 폴더의 png 와 `_result.txt` |
| 계산기에 매물이 안 들어옴 | `helper.log` 에 `가격 검색 결과` 줄이 찍히는지 |

게임 로그 경로를 직접 지정하려면 `설정\settings.json` 의 `"log_path"` 에 적으세요 (`\` 는 `\\` 로).
