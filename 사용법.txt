신들의 강복 도우미 v1.5.1

[실행]
압축을 풀고 ShopHelper.exe 를 더블클릭하세요. 설치할 것은 없습니다. (zip 안에서 바로 실행하지 마세요)
트레이에 결정 아이콘이 생기고, 게임에서 신들의 강복을 열면 자동으로 켜집니다.
게임은 창 모드 또는 테두리 없는 창 모드여야 합니다. UI 크기(한 줄/두 줄)와 해상도는 상관없습니다.

[업데이트]
새 버전 zip 을 같은 폴더에 덮어써서 풀면 됩니다. 입력한 시세는 그대로 남습니다.
시세는 프로그램 폴더가 아니라 %AppData%\ShopHelper\config.json 에 저장됩니다.
(예전 버전에서 exe 옆에 있던 config.json 은 처음 실행할 때 자동으로 옮겨옵니다.)

[표시] 기본은 결정화 기준 (팔아서 결정으로 받을 때, 수수료 12.5% 떼고 올림)
초록 빛 테두리 + '구매 +N결' = 사야 할 칸 (몇 결정 이득인지)
어둡게 눌린 칸 + 빨간 '-N결' = 손해, 회색 = 시세 없음/모르는 항목, 매진 칸은 표시 안 함
노란 테두리 = 신비의 휘석 도박: 효율(평균 획득/가격)과 기대 이득, 최악~최고 범위
왼쪽 아래 시세 창 위의 카드: 이 화면 이득 합계, 지금까지 본 화면의 평균 이득

[시세 입력] 단위: 1개당 결정
- 신들의 강복 안: 게임 화면 왼쪽 아래에 자동으로 뜹니다. [적용](또는 Enter)을 누르면 반영되고 창은 남습니다.
- 상점 밖: 트레이 아이콘 오른쪽 클릭 > 시세 입력 (또는 더블클릭, Ctrl+Shift+P). [입력완료]를 누르면 반영되고 닫힙니다.
- 예) 0.11   1/20 (20개에 1결정)   5.5휘 (휘석으로 입력)   빈칸 = 시세 없음.  '결정 1개 = 50휘석' 도 바꿀 수 있습니다.
- 상점에 목록에 없는 항목이 나오면 자동으로 줄이 추가됩니다. 맨 아래 빈 줄에 직접 추가해도 됩니다.
- 예전 config.json(1개당 휘석)은 처음 실행할 때 자동으로 결정 기준으로 바뀝니다.

[트레이 아이콘 오른쪽 클릭]
- 결정화 기준 / 직접 사용 기준 전환
- 현재 화면 저장: 인식이 이상할 때 누르면 capture_날짜.png 와 _result.txt/png 가 생깁니다. 이 파일을 보내주세요.
- 프로그램 로그 열기 (helper.log, exe 와 같은 폴더)

[한국어 OCR이 없다고 나올 때]
관리자 PowerShell에서:
Add-WindowsCapability -Online -Name "Language.OCR~~~ko-KR~0.0.1.0"
