신들의 강복 도우미 v1.7.5

[실행]
압축을 풀고 ShopHelper.exe 를 더블클릭하세요. 설치할 것은 없습니다. (zip 안에서 바로 실행하지 마세요)
트레이에 결정 아이콘이 생기고, 게임에서 신들의 강복을 열면 자동으로 켜집니다.
게임은 창 모드 또는 테두리 없는 창 모드여야 합니다. UI 크기(한 줄/두 줄)와 해상도는 상관없습니다.

[업데이트]
- 자동: 켤 때와 6시간마다 새 버전을 확인합니다. 새 버전이 있으면 알림이 뜨고, 알림이나 트레이 메뉴 > 업데이트 를 누르면
  받아서 확인(SHA-256)한 뒤 자동으로 바꾸고 다시 시작합니다. 트레이 메뉴에서 자동 확인을 끌 수 있습니다.
- 직접: 새 버전 zip 을 같은 폴더에 덮어써서 풀어도 됩니다.
- 시세는 %AppData%\ShopHelper\prices.json, 설정은 settings.json 에 따로 저장되어 업데이트해도 바뀌지 않습니다.
  (예전 config.json 은 처음 실행할 때 두 파일로 나눠 옮기고 config.json.bak 으로 남깁니다.)

[표시] 기본은 결정화 기준 (팔아서 결정으로 받을 때, 수수료 12.5% 떼고 올림)
초록 빛 테두리 + '구매 +N결' = 사야 할 칸 (몇 결정 이득인지)
어둡게 눌린 칸 + 빨간 '-N결' = 손해, 회색 = 시세 없음/모르는 항목, 매진 칸은 표시 안 함
신비의 휘석(도박)과 매진 칸은 판정하지 않고 표시도 하지 않습니다
[시세 입력] 버튼 위 '순이익': 산 칸(매진으로 바뀐 칸)들의 이득 − 새로고침 횟수 × 휘석 50개 (결정 단위, 켠 뒤부터)
  트레이 메뉴 > 순이익 초기화 로 0 부터 다시 셉니다

[시세 입력] 단위: 1개당 결정
- 신들의 강복 안: 왼쪽 아래에 작은 [시세 입력] 버튼만 뜹니다. 누르면 입력 창이 펼쳐지고,
  [적용](또는 Enter)을 누르면 반영하고 다시 접힙니다. ✕ 나 Esc 는 바꾼 값을 버리고 접습니다.
  구매 창 등 다른 창이 열려 있는 동안은 버튼도 숨깁니다.
- 상점 밖: 트레이 아이콘 오른쪽 클릭 > 시세 입력 (또는 더블클릭, Ctrl+Shift+P). [입력완료]를 누르면 반영되고 닫힙니다.
- 숫자와 소수점만 입력됩니다. 예) 0.11   빈칸 = 시세 없음.  0.000 처럼 적으면 0 으로 정리됩니다.  맨 위 '신력의 휘석 1개 = 0.018 결정' 도 바꿀 수 있습니다.
- 상점에 목록에 없는 항목이 나오면 자동으로 줄이 추가됩니다. 맨 아래 빈 줄에 직접 추가해도 됩니다 (카드에 적힌 이름 그대로).
- 이름 오른쪽 ✕ 로 지울 항목을 고르고 [적용] 하면 지워집니다 (↺ 로 되돌리기). 지운 기본 항목은 업데이트해도 다시 생기지 않습니다.
- 예전 config.json(1개당 휘석)은 처음 실행할 때 자동으로 결정 기준으로 바뀝니다.
- 시세 창 오른쪽 '추천 기준': 이득이 이 값(결정) 이상인 칸만 초록 '구매'. 이득이지만 기준 미달인 칸은 어둡게 + 초록 글씨 (0 = 이득이면 모두 구매)
- 시세 창 오른쪽 아래 '자동 읽기' 슬라이더: 0.1초~1초마다 모든 칸의 숫자를 다시 읽어 잘못 읽은 값을 바로잡습니다 (기본 1초).
  모든 칸을 뒤에서 동시에 읽어서 화면 반응은 느려지지 않습니다. (예전처럼 한 칸씩 읽으려면 settings.json 의 "parallel_reread": false)

[트레이 아이콘 오른쪽 클릭]
- 시세 입력
- 지금 화면 그대로 저장 (Ctrl+Shift+S): 오버레이와 시세 창까지 보이는 그대로 screen_날짜.png 로 저장합니다.
  (오버레이·시세 창은 글자 인식에 섞이지 않도록 일반 캡처 도구에는 안 찍힙니다. 다른 사람에게 보여줄 땐 이걸 쓰세요)
- 현재 화면 저장: 인식이 이상할 때 누르면 capture_날짜.png 와 _result.txt/png 가 생깁니다. 이 파일을 보내주세요.
- 업데이트 확인 / 자동으로 업데이트 확인 켜기·끄기
(로그: exe 와 같은 폴더의 helper.log, 시세 파일: %AppData%\ShopHelper\prices.json)

[글자 인식(OCR)]
따로 설치할 것은 없습니다. Windows 에 한국어/영어 OCR 이 있으면 그걸 쓰고(빠름),
없으면 프로그램에 들어 있는 OCR 을 자동으로 씁니다. 어떤 걸 쓰는지는 helper.log 의 'OCR:' 줄에 나옵니다.
(내장 OCR 은 상점을 처음 열 때 몇 초 걸릴 수 있습니다)

[상점을 열어도 아무것도 안 뜰 때]
게임 로그(UE_game.log)를 보고 상점이 열린 걸 압니다. 게임이 켜져 있으면 그 게임의 로그를 자동으로 고르고,
스팀 라이브러리가 여러 개라 옛 설치 폴더가 남아 있어도 가장 최근에 쓰인 로그로 갈아탑니다.
helper.log 의 '로그:' 줄에 어느 파일을 보는지 나옵니다. 그래도 틀리면
%AppData%\ShopHelper\settings.json 의 "log_path" 에 경로를 직접 적으세요 (\ 는 \\ 로).
